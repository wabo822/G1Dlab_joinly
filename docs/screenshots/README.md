# Captures d’écran

Ce dossier est un **emplacement réservé**. Il ne contient aucune image.

Le dépôt ne versionne pas de capture de l’interface Joinly (accueil, catalogue, fiche, confirmation, billet, contrôle, tableaux de bord). Pour une revue, déposer ici des fichiers PNG ou WebP réellement capturés, par exemple :
